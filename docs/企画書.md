<tr class="odd">
<td><h2 id="ターゲット"><strong>ターゲット</strong></h2>
<p>学部・学年を問わない、学内の学生全体を対象とする。授業内容やキャンパスライフに関する疑問を持つすべての学生が利用者となる。</p>
<h2 id="背景課題"><strong>背景・課題</strong></h2>
<p>学生生活の中では「この授業の課題の進め方が分からない」「履修や手続きについて誰に聞けばよいか分からない」といった疑問が日常的に発生する。SNSや口頭での質問は情報が流れてしまい、同じ疑問を持つ他の学生と共有されにくいという課題がある。</p>
<h2 id="メリット"><strong>メリット</strong></h2>
<ul>
<li><p>質問と回答が蓄積され、同じ疑問を持つ学生が過去の投稿を検索して自己解決できる</p></li>
<li><p>カテゴリ分けにより、授業・学生生活など目的に応じた情報を探しやすくなる</p></li>
<li><p>ベストアンサー機能により、信頼度の高い回答が一目でわかる</p></li>
<li><p>通報機能と管理者による対応により、不適切な投稿を排除し、安心して使える環境を維持できる</p></li>
<li><p>回答者には評価・ランキング・スタンプなどの仕組みがあり、回答する動機づけが得られる</p></li>
</ul>
<h2 id="操作の流れ概要"><strong>操作の流れ（概要）</strong></h2>
<ul>
<li><p>① 会員登録・ログイン → ② 質問を投稿 or 既存の質問を検索・閲覧 → ③
回答を投稿・閲覧 → ④ 「いいね」やベストアンサー選定でよい回答を可視化 →
⑤ 不適切な投稿があれば通報 → ⑥ 管理者が通報内容を確認し対応</p></li>
</ul></td>
</tr>
</tbody>
